# Importação em competência diferente

Quando um documento de Folha, Compras ou Faturamento é importado enquanto o usuário está em outra competência, o arquivo é salvo primeiro na competência detectada e o processamento fica pausado. Um modal central pergunta se a importação deve ser mantida na competência correta. Se o usuário recusar, somente os arquivos recém-importados são removidos e nenhum lançamento é gerado ou sobrescrito.
